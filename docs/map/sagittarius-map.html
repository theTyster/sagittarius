Sagittarius map: groups and flow

Made by python3 kb/share/repo-map/views.py build from MODULES.json, hubkit/tools/store-facts.json and kb/share/repo-map/sagittarius.views.json. Do not edit: views.py check goes red when this page differs from its sources.

Groups view

Each module of MODULES.json is one group, with each part in the one module that covers its path (the except lists hold). What is outside the repo is drawn below it.

Flow view

One row for each step, in the order of time. An arrow goes from the part that acts to the part it writes or reads. A red mark names a step where the store map (store-facts.json) names another owner than the code writes to.

What this map does not draw

  • The install link of each module is one box (install links in ~); no line joins a module to its links (MODULES.json installs names them).
  • No line joins a store to the lane or part that holds it; the lanes name their store in the flow view.
  • orbit report: whether it reads judgments and adoptions was not confirmed (cmd_report names adoption once, judgment never); the s25 arrow does not carry them.
  • Questions and answers of a ticket that waits in a ledger ask are drawn once (the Desk closes the ask); the ask itself is not traced.
