# hub-rotate: the weekly pattern and the rotation

**Local changes:** if `LOCAL.md` exists next to this file, read it now. It holds this hub's changes
to this skill and wins where the two disagree. Do not edit this file: an upgrade replaces it.

The hub is a calendar. `W0/` is the current week, `W5/` five weeks back. Anything older exists only
in git history. Weeks start **Monday**.

## The shape of a week

```
W0/
├── WEEK.md              REQUIRED. Line 1: "# Week of YYYY-MM-DD → YYYY-MM-DD"
├── analyses/            one file or dir per question, named for the question
├── reports/             what went out to people, and how it landed
├── transcripts/         meetings, verbatim. Never deleted.
└── outbound-staging/    drafted, not sent. A human sends. Empty at every rotation.
```

Empty slots are omitted. Flow state (asks, threads, holds, handoffs) is **not** a week slot: it lives
in `flow/flow.db` (skill `hub-flow`), which rotates by age, not by week.

| Slot | Rule |
|---|---|
| `WEEK.md` | Required in every week dir: the dir names rotate, so the dates live here. Never dropped. |
| `analyses/` | States what was measured, how, and **what remains unmeasured**. More than 5 markdown files: add a lean `CLAUDE.md` index. Most likely slot to hold durable content. |
| `reports/` | A report with no outcome is half an artifact. Read them at every rotation for facts other slots lost. |
| `transcripts/` | Never summarised here (that is an analysis), never deleted. |
| `outbound-staging/` | One dir per item; `NOTES.md` line 1 names the surface and recipient. Agents never send. |

## A rotation is non-destructive

- Nothing is removed except `W5/`, by `git rm -r W5/`. Git history is the archive:
  `git log --diff-filter=D -- 'W5/**'`, then `git show <rev>^:W5/<path>`.
- "Not carried forward" means not duplicated into the new `W0`. It never means deleted.
- A live directory **moves** (`git mv`) into the new `W0` and leaves a `TOMBSTONE.md` naming where
  it went. Never copy.
- **A move-forward that carries most of `W1` has failed.** Something there was durable and should
  have been promoted instead.

## The durability check

Before anything stays behind to roll off, ask: **is it durable?** If yes, promote it out of the week
dirs: a root file (`HEURISTICS.md`, `TECHNOLOGIES.md`, `CLAUDE.md`), a skill, or the project docs.
Dropping durable knowledge at a week boundary is the one failure this design can produce.

## Citations

- Name a week by its date range, never by its slot. `W1/` is true for exactly one week.
- Frozen files (`W1/`–`W5/`) get tombstones, never link rewrites. A rewritten frozen link turns a
  visibly dead link into an invisibly wrong one.
- Live files (root files, skills) that name a W-slot get fixed to name the thing instead.

## Procedure

`SK=.claude/skills/hub-rotate/scripts`, `SCR=<a scratch dir>`.

0. **Pre-flight.** Every session that writes into the hub is idle (`ListAgents`; ask busy ones by
   `SendMessage` to reach a stopping point). `git status`: a peer's in-progress file inside a week
   dir is passed with `--leave <path>` and left for its owner. Check `W0/WEEK.md` line 1 is the week
   that just ended. Commit `flow/jsonl/` if dirty.
1. **Citation baseline.** `$SK/check-citations.sh > $SCR/citations-before.tsv`
2. **Flow db dry run.** `python3 .claude/scripts/hubflow.py rotate --week-start <today's Monday>`.
   Read the lapse list. Any item a human still cares about: `hubflow.py renew ID --note "…"` now.
3. **Mechanical rename.** `$SK/rotate.sh --dry-run --leave …`, then `$SK/rotate.sh --leave …`.
   Exit 3: stop and fix. Then `$SK/rotate.sh --verify && git commit -m "rotation <date>: retire W5,
   W4→W5 … W0→W1"`. This one commit has **no** pathspec, on purpose (a pathspec would sweep the
   `--leave` files' unstaged edits in); `--verify` on the line before proves the index holds only
   the rotation.
4. **Editorial lanes.** New `W0/WEEK.md` (rewritten, never copied). Move live analyses with
   tombstones. Move `outbound-staging/` items: sent → `W1/reports/`, unsent → `W0/outbound-staging/`
   with a dated note why. Read `W1/reports/` for lost facts.
5. **Flow db.** `hubflow.py rotate --week-start <today's Monday> --yes`. Put the lapsed and pruned
   ids in the commit message.
6. **Citations after.** `$SK/check-citations.sh > $SCR/citations-after.tsv` and compare with the
   baseline. A citation that broke or now resolves to a different week: tombstone it.
7. **Commit** the editorial half with a pathspec. Report: what moved, what lapsed, what was promoted,
   and anything you could not check.
