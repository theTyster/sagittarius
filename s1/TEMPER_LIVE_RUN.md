`faithful`) and the real System 1 model (jev-1.14.0). Source: "Members got the wrong loyalty
points." The starting falsifiers were passed with `--falsifier`. Default maxn=4. Nothing was tuned
to this run, and it ran once: Ty allowed one live run for package S-B.

The judge's question changed. Collapse: "Is there at least one case, in any system, that would
make the statement false?" (collapsed = no). Faithful: as before, and also false when a system with
none of the problem would make the statement false (such a statement holds a finding about today's
system). The proposer is no longer told to write a statement that a correct system makes false.

Command shape: `python3 s1/temper.py STATEMENT --source SOURCE --item cNN --falsifier F`, with
`TEMPER_LOG` and `S1_LOG` set to one folder per item. The recording was built from those two logs
with `python3 s1/fixtures/build_loopcal_fixture.py RUN_DIR`.

story, "Too strong") did not run: the claim of S-B is about collapse, and the run was kept small.
