orbit-kb help answers: how to read what orbit-kb says

Exit codes
  0  yes. The query is true. Lint is clean.
  1  no. The query has no answer, lint found errors, or the input was rejected.
  2  something is wrong with the question or the tools. Exit 2 is never a no.
     SWI ERROR: the engine could not evaluate the goal. It is not a false answer.
     A line with E1, E2, E17, or E18 before it: a source must be fixed first.

One engine, SWI-Prolog, answers each query. not p holds when p has no answer.

why 'GOAL' (or query --why) prints each answer, then the clauses that prove it:
  "X, because" and, indented under it, why each literal of its rule holds.
  "there is no evidence that X": X has no answer, so not X holds.

whynot 'GOAL' starts with one word:
  holds    GOAL has an answer. The clauses that prove it follow.
  absent   GOAL has no answer. For each rule of GOAL, the literal where it stops follows,
           and why that literal fails. "nothing records X": no fact or rule matches X.
           The survey can have missed it.
The explanations are 6 levels deep. --long goes 30 levels deep. They never change a verdict.

Resume work in a KB: orbit-kb show open. It names each item that blocks done, each thing
that blocks discovery_ready while the discovery orbit is open, and each stale pin that the
KB rests on. It says "Nothing is open" only when none holds.
