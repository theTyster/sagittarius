orbit-kb help codes: lint codes (E: error, exit 1; W: warning)
Each message ends with the fix. Read it. orbit-kb lint --strict makes warnings errors.

Core
  E1   syntax error. Query, why, whynot, show, and report exit 2.
  E2   undeclared predicate or wrong arity. Fix the name, or add a fact of the new kind:
       orbit-kb add 'FACT' --doc TEXT.
  E3   type error (also a label outside oneof)
  E4   dangling reference: the id does not exist, or is the wrong kind (also depends_on, excludes, ratified_by of the project module).
       supersedes takes two claims, or two hypotheses, or (project module) two decisions, two definitions, or two rules.
       The other project relations (decided_by, analysis, concerns) refuse a missing id too.
  E5   duplicate id
  E6   non-ground fact in kb.pl
  E7   a clause in the wrong place (a rule as a fact in kb.pl, or a fact outside kb.pl)
  E8   this writer may not write this attestation type
  E9   a test_result or lean_proof with no matching run log. Use orbit-kb run / prove.
  E10  uses/1 is missing, not first, or names an unknown module
  E11  a clause does not load in the SWI engine
  E14  unsafe negation: a not variable is in the head but in no positive body literal
  E15  supersedes cycle. add refuses it. done is false while it exists.
  E16  rules.pl adds clauses to a protected predicate (done, burn and flare rules, blocking rules, vote rules). Ignored.
  E17  a form that orbit-kb does not read: classical negation -p, a # line, a global
       constraint (:- Body), or a #= constraint. add refuses it. Query, why, whynot,
       show, and report exit 2 until it is gone.
  E18  the rules are not stratified: a predicate depends on itself through not.
       Query, why, whynot, show, and report exit 2 until it is gone.
  E19  typo guard: a predicate declared by its first use (add) has a name 2 edits or
       fewer from a declared predicate of the same arity. The message names both.
       A typo: withdraw the new kind, and add its facts again under the declared name:
         orbit-kb withdraw cited/2     removes its declaration and its facts, with a record
       Never edit kb.pl by hand. A new predicate: choose a name more than 2 edits away.
       Also a head of rules.pl (declared by its first clause) that is that close to a declared name:
       correct the name in rules.pl. Query, why, whynot, show, and report exit 2 until it is gone.
  W1   subject digest differs from the file. Run orbit-kb subject again.
  W2   a local declaration, listed for review
  W3   a claim with no cites. Cite the request text, or drop the claim (drift).
  W4   a local fact predicate that no rule reads
  W5   a check tests a replaced claim, and the new claim has none. Add a new check. Run it.
  W6   a local rule extends a core or module predicate
  W7   a predicate declared by its first use (add), with who and when. Review it:
       is it needed, and is the name right? Its arguments have the type term.
  W8   the request text changed at its source (request_pin, T27): read the tracker item. A human
       accepts the new text with orbit-kb pin-request --request-file F --accept --by human.
       It also blocks done (request_stale) until then.
  W9   a fact kind of kb.pl, or a head of rules.pl, with no description (T26). For a fact kind: give one in
       the first add, or in any later add of one of its facts while it has none: orbit-kb add 'FACT' --doc TEXT.
       For a rule head (also an old decl(rule, ...) line of kb.pl with no doc): a line %% doc: TEXT just
       above its first clause in rules.pl. orbit-kb show kinds names each one, also while E19 or E2 fires.
  W10  a current hypothesis has no premise and no record no_premises(H) (D30). Add
       premise(P, H, Text) for each condition that it takes as given, or no_premises(H).
  W11  a current hypothesis has a premise and also no_premises(H). They contradict. Restate the
       hypothesis (supersedes) with its premises, or with no_premises only.

Discovery module
  WD1  a conflict, surprise, or scope finding raised no question. Ask one.
  WD2  a model states a claim but is not trusted. Make it sane and calibrated.
  WD3  a rule survived its mutation, with no reason. Find out why. Add a reason.
  WD4  only a model shows this finding. Confirm it on the system, or report a lead.
  WD5  a result is unknown. Report a gap, never UNSAT.
  WD6  the problem did not reproduce. Tell the human what you tried.
  WD7  a hypothesis has no system result. Reproduce it, or ask if it is another ticket.
       A superseded hypothesis needs none, and none is asked while the discovery orbit is
       closed (the human approved the ticket after a GO; BACK opens it again).
  WD8  this result's log has a run of an older model file. Run orbit-kb subject on the
       model. Run the solver into a new log. When a newer result of the same check
       exists, the message says so, and nothing is left to do.
  WD9  the human voted and you did not vote in that round. Vote before the human next round.
  WD10 a current claim has no example. Discovery is not ready until each current claim has
       one: add example(C, Text). Not asked while the discovery orbit is closed.
  ED1  a reproduction is not on system evidence. Use a log, query, or test tagged system.
  ED2  a model result has no model_run for its log. Add it.
  ED3  the model disagrees with the system, or the existing-world model misses the bad case.
  ED4  a claim can never apply. Fix the model, or ask the human.
  ED5  a model breaks a current claim. File a disproof with refuted(Counterexample).
  ED6  two solver results of the same kind, for one model, disagree. Find the cause.
  ED7  a claim replaces a refuted or contested claim with no human answer. Ask the human.
  ED8  no finding or hypothesis raised this question. Correct raised_by.
  ED9  a model is derived from a derived model, or from itself. Derive from existing-world models.
  ED10 a writer voted twice in one round. Keep one vote. After a HOLD, vote in the next round.
  ED11 a discovery_end that names no human approval of the ticket. Only attest approval writes
       it; it does not close the orbit. Remove the line.
What blocks discovery_ready blocks GO: orbit-kb show open names each item (ready_blocker),
and the tool refuses an agent's GO vote while one is left. Also orbit-kb whynot 'discovery_ready'.

Build module (orbit-kb help build)
  WR1  a current claim is not independently verified, and a review is due: no claim is under
       (D28, T38). A reviewer of another role and session reruns a check of it after its
       last change (orbit-kb run --as ROLE), then records an upheld verdict that rests on
       that run (attest disproof --rests-on). Only in a KB that records actors or a review.
       A warning: it does not block done.

Project module (orbit-kb help project)
  WP1  a pins fact: the decision (or definition or rule) changed since the claim was written. Read it, then pin the new digest.
  WP2  a pins fact that cannot be checked: no project_kb, no kb.pl there, or no such decision, definition or rule.
  WP3  the project KB has a lint error, so a conflict could hide in it. Run orbit-kb lint on it.
       It also blocks (project_kb_unclean).
  WP4  a KB has more than one project_kb fact. Only the first is read. Keep one.
  WP5  a claim pins a fact that rests on a fact in a contradiction. A warning: only a direct pin blocks.
  WP6  an analysis path is outside the project KB. Move the file under analyses/ of the project KB.
  WP7  a fact rests on itself: its depends_on facts make a cycle. A warning: check each depends_on of the cycle.
  WP8  a stale pin that the KB still rests on (a current decision or definition, or nothing names it and
       its source has no newer pin). Read it; pin the source again and move the concerns facts. show open names it.
  WP9  only an agent wrote this relation (relation_by): it is proposed and blocks nothing. A human
       ratifies it by adding the same relation with --by human.
  EP1  an agent (agent or agent:NAME, in any case) ratified a fact (an error; add refuses it). Only a human ratifies.
  EP2  a fact depends on itself or excludes itself (depends_on(X, X), excludes(X, X); an error; add refuses it).
